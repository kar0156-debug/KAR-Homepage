# ③ 온라인 신청 폼 소스 설명

온라인 신청 4종은 **HTML · CSS · Vanilla JavaScript**(외부 라이브러리 없음)로 만들어져 있으며, 화면은 `data.js` 의 설정을 읽어 자동으로 그려집니다.
**평소에는 `data.js` 만 고치면 됩니다.**

## 1. 파일 구성
| 파일 | 역할 | 수정 |
|---|---|---|
| `index.html` | '온라인 신청' 영역의 틀(탭 · 패널 자리) | 거의 없음 |
| `data.js` → `KAR.formSubmit` | 첨부 한도(합계 15MB · 개수 제한 없음) · 허용 확장자 · 메일 모양 · 전송 방식 | 가끔 |
| `data.js` → `KAR.formFootnotes` | 모든 폼 아래 ※ 안내 1·3번째 줄 | 가끔 |
| `data.js` → `KAR.onlineForms` | **신청별 접수 주소 · 항목 · 안내 문구** | 자주 |
| `assets/js/app.js` (2. 온라인 신청) | 폼 그리기 · 조건부 항목 · 드래그 앤 드롭 · 전송 · 로딩/완료 표시 | 수정 불필요 |
| `assets/css/style.css` (온라인 신청 폼) | 입력칸 · 첨부 영역 · 버튼 디자인 | 수정 불필요 |

## 2. 코드에 넣는 '키' — endpoint 하나
```js
// data.js  → KAR.onlineForms → 각 신청
endpoint: "https://formsubmit.co/ajax/edu@kar.re.kr",      // ← 받는 주소(또는 활성화 후 받은 문자열)
cc: "",                                                     // ← 참조 주소(여러 개면 쉼표)
fallbackEmail: "edu@kar.re.kr",                             // ← 제출 실패 시 화면에 안내할 주소
subject: "[홈페이지 온라인 신청] 교육 신청",                  // ← 받는 메일 제목
```
별도의 API 키 · 비밀번호는 없습니다. (활성화 방법은 ② 가이드)

## 3. 항목(fields) 고치기
각 항목은 `{ label: "항목명", type: "종류", ... }` 한 줄입니다. **label 이 화면 제목이자 메일의 항목명**이며, 한 폼 안에서 겹치면 안 됩니다.

| type | 화면 | 예시 |
|---|---|---|
| `"text"` | 한 줄 입력 | `{ label: "이름", type: "text" }` |
| `"textarea"` | 여러 줄 입력 | `{ label: "추가 요청사항", type: "textarea" }` |
| `"date"` | 날짜 선택 | `{ label: "생년월일", type: "date" }` |
| `"email"` | 이메일 | `{ label: "수신 이메일(개인)", type: "email", replyTo: true }` (replyTo = 메일 '답장'이 이 주소로) |
| `"select"` | 목록 선택 | `{ label: "응시분야", type: "select", options: ["ISO 9001 (QMS)", "..."] }` |
| `"radio"` | 하나 선택 | `{ label: "응시일자", type: "radio", options: ["2026년 12월 18일"] }` |
| `"agree"` | 동의 체크 | 서약서처럼 긴 글(desc) + '동의합니다' 체크 |
| `"section"` | 소제목 · 안내(입력칸 아님) | `{ type: "section", title: "회사 명의 발급 정보", desc: "..." }` |

공통 옵션
- `desc: "안내 문구"` — 항목 아래 회색 설명 (줄바꿈은 `\n`)
- `placeholder: "예) 1990.01.01"` — 입력칸 속 예시
- `required: true` — 필수 입력 (현재는 기존 구글 폼과 같게 **모두 선택 입력**)
- `showIf: { field: "발급 명의 선택", value: "회사명의" }` — 그 항목에서 해당 값을 골랐을 때만 표시. 숨겨진 항목은 메일에 포함되지 않습니다.

### 자주 하는 수정 예
- **교육 과정 목록 바꾸기** : `id: "edu"` → `"온라인 교육 신청"` 의 `options` 배열에서 줄을 추가·삭제
- **시험 일자 바꾸기** : `id: "exam"` → `"응시일자"` 의 `options` 를 `["2027년 1월 22일"]` 처럼 변경
- **필수 항목 지정** : 원하는 항목 끝에 `, required: true` 추가 → 비우면 제출 전에 안내
- **첨부 영역 끄기/켜기** : 해당 신청의 `attach: true / false`
- **안내 2번째 줄(신청별 개인정보 문구)** : 해당 신청의 `privacy`

## 4. 동작 방식 (참고)
1. 탭을 고르면 해당 신청 폼이 표시됩니다. (`자격인증 신청 › 교육 신청 › 자격시험 신청 › 자격인증서 발급 신청 › 영수증 신청·출력` — 자격인증 신청은 ④·⑤ 가이드, 교육 신청 탭 위쪽에는 교육 과정 안내가 함께 표시)
2. **첨부** : 점선 상자에 파일을 끌어다 놓거나 클릭해 선택 → 목록 · 합계 용량 막대 표시. 형식이 다르거나 5개/10MB를 넘으면 안내하고 받지 않습니다.
3. **제출** : 버튼이 **'제출 중...'**(회전 표시)으로 바뀌고 잠깁니다 → 입력값 + 첨부파일을 FormSubmit 으로 전송
4. **완료** : '신청이 접수되었습니다' 화면 표시, '새 신청서 작성'으로 처음부터 다시 작성
5. **실패** : 빨간 안내 + 담당자 전화 · 메일 안내 (입력한 내용은 그대로 남음)
6. **로봇 차단** : 사람에게 보이지 않는 숨김칸(`_honey`)에 값이 들어오면 조용히 무시

### 메일로 보내지는 값
| 이름 | 내용 |
|---|---|
| `_subject` | 메일 제목 |
| `_template` | `table` (표 형식) |
| `_captcha` | `false` (AJAX 전송은 화면 인증을 쓸 수 없어 숨김칸 방식으로 대신함) |
| `_cc` | 참조 주소 (설정 시) |
| `신청 구분` | 교육 신청 / 자격시험 신청 … |
| 각 항목 label | 신청자가 입력한 값 |
| `email` | 수신 이메일(영수증) — 메일 '답장' 대상 |
| `접수번호` | KAR-날짜-시각-4자리 |
| `첨부파일_폴더` · `첨부파일_링크` · `첨부파일N_이름/링크` | 구글 드라이브 링크 (파일은 `assets/js/drive-upload.js` 가 Apps Script 로 먼저 올림) |

## 5. 보안 메모
- 홈페이지에는 서버 프로그램 · DB · 로그인이 없습니다. 신청 데이터는 브라우저에서 FormSubmit 으로 바로 전송됩니다.
- `index.html` 의 보안 정책(Content-Security-Policy)은 **FormSubmit(formsubmit.co) 외의 곳으로는 전송할 수 없도록** 막혀 있습니다. 다른 전송 서비스로 바꿀 때는 이 정책의 `connect-src` · `form-action` 도 함께 바꿔야 합니다.
