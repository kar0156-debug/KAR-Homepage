# ⑤ 자격인증 신청 소스 설명

'자격인증 신청'은 **온라인 신청 섹션의 첫 번째 탭**입니다(퀵 버튼 '자격인증 신청'을 누르면 이 탭이 열림). HTML · CSS · JavaScript 가 파일별로 분리되어 있고, 외부 라이브러리 없이 동작합니다. **평소에는 `data.js` 의 `KAR.certApply` 만 고칩니다.**

| 파일 | 내용 | 수정 |
|---|---|---|
| `index.html` → '온라인 신청' 섹션 안 `<div id="panel-qual">` | '자격인증 신청' 탭(맨 앞, 기본 열림)의 폼 화면 + 완료 팝업 `<dialog id="ca-done">` | 문구 바꿀 때 |
| `assets/css/cert-apply.css` | KAR 적색(`--red`) · 청색(`--navy`, `--b1`) 디자인, 모바일 대응 | 불필요 |
| `assets/js/cert-apply.js` | 파일 검사 → Firebase 업로드 → FormSubmit 전송 → 팝업 | 불필요 |
| `data.js` → `KAR.certApply` | ★Firebase 키 · ★접수 메일 · 제한값 · 선택 항목 · 안내 문구 | **여기만** |
| `data.js` → `KAR.requiredDocs` | 유형·등급별 제출 서류 안내(서식 섹션의 표와 같은 데이터) | 서류가 바뀔 때 |
| `docs/firebase/storage.rules` | Firebase 보안 규칙 원본 (콘솔에 붙여 넣는 용) | 제한값을 바꿀 때 같이 |

## 1. 화면 항목 (모두 필수)
| 구분 | 항목 | 입력 방식 |
|---|---|---|
| 신청인 정보 | 성명 · 생년월일 · 연락처 · 이메일 주소 | 입력칸 (연락처는 숫자·- 형식, 이메일은 형식 검사) |
| 신청 내용 | 신청 유형 | 신규 등록 / 승급 / 갱신 / 전환 / 심사수행범위 추가 중 1개 → **받는 메일 결정** |
| | 신청 등급 | 심사원보 / 심사원 / 선임심사원 / 검증심사원 |
| | 인증 스킴 | 17개 분야 중 1개 이상(복수 선택) |
| 증빙서류 | 첨부파일 | 드래그 앤 드롭 또는 클릭 · 1~3개 · 파일당 30MB · .pdf .hwp .docx .xlsx .jpg |

유형·등급을 고르면 첨부 영역 위에 **제출 서류 목록**과 '서식 내려받기' 링크가 자동으로 나옵니다(제출 여부는 검사하지 않음).

## 2. 바꿀 수 있는 값 (data.js → KAR.certApply)
```js
maxFiles: 3,                 // 최대 파일 수
maxFileMB: 30,               // 파일당 최대 용량(MB)  ← storage.rules 의 30 * 1024 * 1024 와 같이
accept: [".pdf", ".hwp", ".docx", ".xlsx", ".jpg"],   // ← storage.rules 의 (pdf|hwp|docx|xlsx|jpg) 와 같이
storageFolder: "applications",                        // ← storage.rules 의 /applications/ 와 같이
keepDays: 30,                // 메일 안내 문구용(실제 삭제는 수명 주기 규칙)
types:  [...], grades: [...], schemes: [...],          // 선택 항목
footnotes: [...],            // 폼 아래 ※ 안내
```
- 형식을 추가하려면(예: .png) ① `accept` 에 추가 ② `assets/js/cert-apply.js` 맨 위 `MIME` 표에 `'.png': 'image/png'` 추가 ③ 보안 규칙의 형식 두 곳에 추가 → 세 곳을 함께 바꿉니다.
- 신청 유형 이름을 바꾸면 `routes` 의 이름도 같게 바꿉니다.

## 3. 동작 순서 (assets/js/cert-apply.js)
1. **검사** : 필수 항목 → 인증 스킴 1개 이상 → 첨부 1개 이상. 파일은 넣는 순간 확장자 · 30MB · 3개 · 빈 파일을 검사해 안내(toast)하고 받지 않습니다.
2. **업로드** : 버튼이 **'제출 중...'** 으로 바뀌고 잠김, 진행 막대에 "파일 업로드 중 (1/3)" 표시
   - 위치 : `applications/2026-11-08/KAR-20261108-143015-AB12_무작위16자/1_파일명.pdf`
   - 방식 : `POST https://firebasestorage.googleapis.com/v0/b/<storageBucket>/o?uploadType=media&name=<위치>`
   - 응답의 다운로드 토큰으로 `…/o/<위치>?alt=media&token=<토큰>` 링크 생성
3. **메일 전송** : FormData 로 `https://formsubmit.co/ajax/<유형별 메일>` 에 전송
   - 보내는 값 : `_subject` · `_template=table` · `_captcha=false` · `_replyto=신청인 이메일` · 접수번호 · 신청 유형 · 신청 등급 · 인증 스킴 · 성명 · 생년월일 · 연락처 · 이메일 · 증빙서류 1~3(파일명 + 링크) · 파일 보관 안내
4. **완료** : **"접수가 완료되었습니다."** 팝업(접수번호 표시) → [확인] 누르면 폼 초기화
5. **실패** : 빨간 안내 + 담당자 메일 안내(입력 내용 유지). 숨김칸(로봇 차단)에 값이 있으면 조용히 무시

## 4. 보안 설정 (index.html 의 Content-Security-Policy)
`connect-src` 에 `https://formsubmit.co https://firebasestorage.googleapis.com` 만 허용되어 있어, 이 두 곳 외의 서버로는 데이터를 보낼 수 없습니다. 외부 스크립트는 쓰지 않습니다(`script-src 'self'`).
