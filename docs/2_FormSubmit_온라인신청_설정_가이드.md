# ② FormSubmit 온라인 신청 설정 가이드

홈페이지 '온라인 신청'(교육 · 자격시험 · 자격인증서 발급 · 영수증 신청·출력)은 **FormSubmit**(formsubmit.co)으로 동작합니다.
신청자가 입력한 내용과 첨부파일이 **담당자 메일(메일나라)로 바로 도착**하는 단방향 방식이며, 홈페이지에는 아무것도 저장되지 않습니다.

| 항목 | 내용 |
|---|---|
| 요금 · 가입 | **무료 · 회원가입 없음** (접수 메일 주소를 한 번 '활성화'만 하면 됨) |
| 첨부파일 | 신청 1건당 **합계 10MB** 이하 (홈페이지에서 최대 5개 · 합계 10MB로 미리 제한) |
| 신청 건수 | 제한 없음 (스팸 방지를 위해 FormSubmit이 수시로 제한할 수 있음) |
| 보관 | FormSubmit 서버에 신청 내용 **30일** 보관, 첨부파일은 보관하지 않음 → 홈페이지 안내 문구에 명시됨 |
| 발신 | 메일은 FormSubmit 발신 주소로 도착합니다. 신청자에게 바로 답장하려면 신청서의 수신 이메일을 확인하세요(영수증 신청은 '답장'이 신청자에게 가도록 설정됨) |

> 참고 : EmailJS는 무료 요금제에서 첨부파일이 안 되고(유료 Business $40/월부터 30MB), Firebase 파일 저장소는 카드 등록(Blaze)이 필요해 **FormSubmit 단독**으로 구성했습니다.

| 신청 | 받는 주소 | 참조(CC) | data.js 위치 |
|---|---|---|---|
| 교육 신청 | kar0156@kar.re.kr | – | `KAR.onlineForms` → `id: "edu"` |
| 자격시험 신청 | kar0159@kar.re.kr | – | `id: "exam"` |
| 자격인증서 발급 신청 | kar0159@kar.re.kr | kar0154@kar.re.kr | `id: "cert"` |
| 영수증 신청·출력 | kar0157@kar.re.kr | – | `id: "receipt"` |

data.js 의 `endpoint` 값이 "코드에 넣는 키(Key)" 역할을 합니다. **바꿀 곳은 이 값 하나뿐**입니다.
```js
endpoint: "https://formsubmit.co/ajax/kar0156@kar.re.kr",
```

## 2. 처음 한 번 : 접수 메일 주소 활성화 (주소마다)
FormSubmit은 처음 받는 주소로 **"이 주소로 신청서를 받으시겠습니까?" 확인 메일**을 보냅니다. 승인 전에는 신청이 전달되지 않습니다.

1. 홈페이지를 GitHub Pages에 올린 뒤(① 가이드 4단계), **실제 홈페이지 주소**에서 접속합니다.
   - PC에 있는 index.html 을 직접 열어 시험하지 마세요. FormSubmit은 신청이 들어온 웹 주소를 기준으로 폼을 구분합니다.
2. '온라인 신청 → 교육 신청'에 시험용 내용(이름 : 테스트)을 넣고 **신청서 제출**
   - 화면에 "접수 메일 주소의 사용 승인(활성화)이 아직 완료되지 않았습니다" 같은 안내가 나와도 정상입니다.
3. `kar0156@kar.re.kr` 메일함(메일나라)에서 **FormSubmit** 이 보낸 메일 확인 → **Activate Form** 버튼 클릭
   - 받은편지함에 없으면 **스팸함**을 확인하고, 메일나라 스팸 설정에서 `formsubmit.co` 를 **수신 허용**에 등록합니다.
4. 같은 내용으로 **한 번 더 제출** → 메일함에 신청 내용(표 형식)이 도착하면 성공
5. 나머지 3개 신청(자격시험 → kar0159, 자격인증서 → kar0159·kar0154, 영수증 → kar0157)도 똑같이 반복합니다.
   - 자격인증서의 참조 주소(kar0154)에도 확인 메일이 오면 같이 승인합니다.

## 3. (권장) 홈페이지 소스에서 메일 주소 숨기기
활성화 메일 또는 첫 신청 메일에 **임의 문자열(예: `7f3a9c1e5b2d…`)**이 함께 옵니다. 이 문자열을 주소 대신 쓰면 스팸 수집기가 소스에서 메일 주소를 가져갈 수 없습니다.

1. GitHub에서 `data.js` → 연필(Edit)
2. 해당 신청의 `endpoint` 에서 메일 주소 부분만 문자열로 교체
   ```js
   endpoint: "https://formsubmit.co/ajax/7f3a9c1e5b2d4a6f8e0c1b3d5a7f9e2c",
   ```
3. Commit → 1~2분 뒤 한 번 더 시험 제출해 정상 도착 확인
   - `cc`(참조) 주소는 문자열로 바꿀 수 없으니 그대로 둡니다.

## 4. 시험 제출 체크리스트 (활성화 후 · 도메인 연결 후 각 1회)
- [ ] 4개 신청 모두 **제출 → '신청이 접수되었습니다'** 화면이 뜬다
- [ ] 담당자 메일에 **제목 `[홈페이지 온라인 신청] ○○`** 으로 표 형식 메일이 온다
- [ ] **첨부파일**(HWP · PDF 각 1개)이 메일에 붙어 온다 — 교육 · 자격시험 · 영수증
- [ ] 영수증 신청 : 개인명의/회사명의, 청구용/영수용을 바꿔 가며 **선택한 쪽 항목만** 메일에 들어온다
- [ ] 자격인증서 : kar0154 에도 참조 메일이 온다

### 첨부파일이 메일에 오지 않으면 (예비 방식)
기본은 페이지 이동 없이 보내는 **AJAX 방식**입니다. 혹시 첨부가 빠져 오면 `data.js` 에서 한 단어만 바꿉니다.
```js
mode: "post",   // 원래 "ajax"
```
→ 제출하면 잠깐 FormSubmit 화면을 거쳐 홈페이지로 돌아오고 '신청이 접수되었습니다'가 표시됩니다.

## 6. 문제 해결
| 증상 | 확인할 것 |
|---|---|
| 제출은 되는데 메일이 안 옴 | ① 활성화(2단계)를 했는지 ② 스팸함 ③ 메일나라 수신 허용에 `formsubmit.co` 등록 |
| "제출하지 못했습니다" | 인터넷 연결 · 회사 보안 프로그램이 formsubmit.co 를 막는지 확인. 계속되면 안내된 담당자 메일로 신청서를 받습니다 |
| 첨부가 빠짐 | 4단계 '예비 방식'(`mode: "post"`) 사용 · 합계 10MB 이하인지 확인 |
| 같은 신청이 두 번 옴 | 신청자가 버튼을 두 번 누른 경우 — 제출 중에는 버튼이 잠기도록 되어 있으나, 새로 고침 후 다시 낸 경우일 수 있음 |
| 스팸 신청이 옴 | 숨김 항목(자동 입력 로봇 차단)이 기본 적용됨. 심하면 `data.js` 의 endpoint 를 3단계 문자열로 바꾸고, 계속되면 담당자에게 문의 |

## 7. 개인정보 · 보안 메모
- 홈페이지 폼 아래 안내 : "※ 신청 시, 개인정보 이용에 동의한 것으로 간주하며, FormSubmit은 접수된 신청 내용을 30일 동안 FormSubmit 서버에 보관합니다(첨부파일은 보관하지 않음)."
- FormSubmit은 해외(미국) 서비스입니다. 기관 개인정보처리방침에 '온라인 신청 접수 위탁(FormSubmit)' 항목 반영 여부를 개인정보 담당자와 확인하세요.
- 주민등록번호 · 계좌 비밀번호 등은 입력받지 않습니다(현재 폼에 없음).
- 받은 신청 메일은 처리 후 보관 기간에 맞춰 정리합니다.
