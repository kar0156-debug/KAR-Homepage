# ⑤ 자격인증 신청 소스 설명

'자격인증 신청'은 **온라인 신청 섹션의 첫 번째 탭**입니다(퀵 버튼 '자격인증 신청'을 누르면 이 탭이 열림). HTML · CSS · JavaScript 가 파일별로 분리되어 있고, 외부 라이브러리 없이 동작합니다. **평소에는 `data.js` 의 `KAR.certApply` 만 고칩니다.**

| 파일 | 내용 | 수정 |
|---|---|---|
| `index.html` → '온라인 신청' 섹션 안 `<div id="panel-qual">` | 폼 화면 + FormSubmit 숨김 input + 완료 팝업 `<dialog id="ca-done">` | 문구 바꿀 때 |
| `assets/css/cert-apply.css` | KAR 적색 · 청색 디자인, 모바일 대응 | 불필요 |
| `assets/js/cert-apply.js` | 검사 → Base64 → Apps Script → 드라이브 링크 대입 → FormSubmit → 팝업 | 불필요 |
| `data.js` → `KAR.certApply` | ★Apps Script URL · ★접수 메일 · 제한값 · 선택 항목 · 안내 문구 | **여기만** |
| `data.js` → `KAR.requiredDocs` | 유형·등급별 제출 서류 안내(서식 섹션의 표와 같은 데이터) | 서류가 바뀔 때 |
| `docs/apps-script/Code.gs` | 구글 드라이브 저장용 Apps Script 원본 (script.google.com 에 붙여 넣는 용) | ★FOLDER_ID |

## 1. 화면 항목 (모두 필수)
| 구분 | 항목 | 입력 방식 |
|---|---|---|
| 신청인 정보 | 성명 · 생년월일 · 연락처 · 이메일 주소 | 입력칸 (연락처는 숫자·- 형식, 이메일은 형식 검사) |
| 신청 내용 | 신청 유형 | 신규 등록 / 승급 / 갱신 / 전환 / 심사수행범위 추가 → **받는 메일 결정** |
| | 신청 등급 | 심사원보 / 심사원 / 선임심사원 / 검증심사원 |
| | 인증 스킴 | 17개 분야 중 1개 이상(복수 선택) |
| 증빙서류 | 첨부파일 | 드래그 앤 드롭 또는 클릭 · 1개 이상 · **합계 15MB 이하**(개수 제한 없음) · .pdf .hwp .docx .xlsx .jpg |

유형·등급을 고르면 첨부 영역 위에 **제출 서류 목록**과 '서식 내려받기' 링크가 자동으로 나옵니다. 첨부 목록 아래에는 **합계 용량 막대**(예: 합계 11.0MB / 15MB)가 표시됩니다.

## 2. 바꿀 수 있는 값 (data.js → KAR.certApply)
```js
appsScriptUrl: "https://script.google.com/macros/s/…/exec",  // ★ Apps Script 웹 앱 URL
routes: { "신규 등록": { to: "kar0159@kar.re.kr" }, … },      // ★ FormSubmit Action 이메일
maxTotalMB: 15,              // 첨부 합계 한도  ← Code.gs 의 MAX_TOTAL_MB 와 같이
maxFiles: 0,                 // 최대 파일 수 (0 = 제한 없음)
accept: [".pdf", ".hwp", ".docx", ".xlsx", ".jpg"],   // ← Code.gs 의 ALLOWED_EXT 와 같이
keepDays: 30,                // 메일 안내 문구용 (실제 삭제는 Code.gs 의 KEEP_DAYS)
sendMode: "ajax",            // 메일이 안 오면 "post"
debug: false,                // 시험할 때 true
types / grades / schemes / footnotes                   // 선택 항목 · 폼 아래 ※ 안내
```
- 형식을 추가하려면(예: .png) ① `accept` ② `assets/js/cert-apply.js` 맨 위 `MIME` 표 ③ Code.gs 의 `ALLOWED_EXT` 세 곳을 함께 바꿉니다(Code.gs 는 새 버전으로 다시 배포).

## 3. 동작 순서 (assets/js/cert-apply.js · async/await)
제출 버튼을 누르면 브라우저 기본 제출을 막고(`e.preventDefault()`), 아래 단계를 **앞 단계가 끝난 뒤에** 진행합니다.

1. **검사** : 필수 항목 → 인증 스킴 → 첨부 1개 이상 → **첨부 합계 15MB 초과 시 경고창**(파일을 넣을 때와 제출 직전 두 번 확인)
2. **Base64 변환** (`await toBase64()`) : `FileReader.readAsDataURL` → 앞의 `data:…;base64,` 제거
3. **Apps Script 전송** (`await uploadToDrive()`)
   - `POST <appsScriptUrl>` · `Content-Type: text/plain` (브라우저 사전 요청 없이 전달되도록)
   - 본문 : `{ applyNo, name, type, honey, files: [{ name, mimeType, data(Base64) }] }`
   - 응답 : `{ ok: true, folderUrl, files: [{ name, size, url }] }` — 링크가 파일 수만큼 없으면 **메일을 보내지 않고** 오류 안내
4. **숨김 input 대입** (`fillHiddenInputs()`)
   - `첨부파일_폴더` ← 신청 폴더 링크 · `첨부파일_링크` ← 파일 링크 전체(` , ` 구분) · `첨부파일N_이름` / `첨부파일N_링크` ← 파일별
5. **메일 전송** (`await sendAjax()`) : `new FormData(form)` 을 `https://formsubmit.co/ajax/<유형별 메일>` 로 전송
   - 메일 표 순서 : 접수번호 · 성명 · 생년월일 · 연락처 · 이메일 · 신청 유형 · 신청 등급 · 인증 스킴 · 첨부파일_폴더 · 첨부파일_링크 · 첨부파일N_이름/링크 · 파일 보관 안내
6. **완료** : **"접수가 완료되었습니다."** 팝업(접수번호) → [확인] 누르면 폼 초기화
7. **실패** : 빨간 안내 + 담당자 메일 안내(입력 내용 유지)

### 시험할 때 : 처리 과정 보기
`debug: true` 로 바꾸면 폼 아래에 **Apps Script 응답 · 드라이브 링크 · FormSubmit 으로 보낸 값**이 표시됩니다(F12 → Console 에도 `[KAR 자격인증 신청]` 으로 기록). 시험 후에는 `false` 로 돌려 두세요.

## 4. Apps Script (docs/apps-script/Code.gs)
| 함수 | 하는 일 |
|---|---|
| `doPost` | 파일 수신 → 확장자·합계 15MB·접수번호 형식·로봇 숨김칸 검사 → 하위 폴더 「접수번호_성명_유형」 생성 → 파일 저장 → 링크 JSON 반환 (공개 공유 안 함) |
| `doGet` | 동작 확인용 `{"ok":true,…}` |
| `cleanupOldFolders` | 30일 지난 신청 폴더 → 휴지통 (매일 자동) |
| `setupDailyCleanup` · `checkSetup` | 처음 한 번 직접 실행 (자동 정리 예약 · 권한 승인/폴더 확인) |

## 5. 보안 설정 (index.html 의 Content-Security-Policy)
`connect-src` 에 `https://formsubmit.co https://script.google.com https://script.googleusercontent.com` 만 허용되어 있어, 이 곳 외의 서버로는 데이터를 보낼 수 없습니다(Apps Script 응답은 script.googleusercontent.com 을 거쳐 돌아옴). 외부 스크립트는 쓰지 않습니다(`script-src 'self'`).
