# ④ Google Apps Script + 구글 드라이브 자격인증 신청 연동 가이드

'자격인증 신청'은 카드 등록 없이 **무료**로, 신청자 로그인 없이 증빙서류를 받습니다.

```
신청자 : 정보 입력 + 증빙서류 첨부(합계 15MB 이하, 개수 제한 없음)
   │
   ├─①→ Google Apps Script 웹 앱 : 파일(Base64) 수신 → 구글 드라이브 '자격인증 신청' 폴더에 저장
   │        └ 신청마다 하위 폴더 「접수번호_성명_유형」 → 폴더·파일 링크를 홈페이지에 돌려줌
   │
   └─②→ FormSubmit : 신청 내용 + 드라이브 링크 → 담당자 메일
          · 신규 등록 · 승급 · 심사수행범위 추가 → kar0159@kar.re.kr
          · 갱신 · 전환                       → kar0156@kar.re.kr
```

| 항목 | 내용 |
|---|---|
| 비용 | 무료 (구글 계정 1개 · 카드 등록 없음) |
| 첨부 한도 | 신청 1건 합계 **15MB** — 넘으면 홈페이지가 제출 전에 경고 |
| 링크 공개 범위 | **공개 공유 안 함.** 저장 폴더를 공유받은 담당자 구글 계정으로 로그인해야 열림 |
| 보관 | 30일 지난 신청 폴더는 매일 자동으로 휴지통 이동(휴지통은 30일 뒤 영구 삭제) |
| 관리자가 바꾸는 곳 | ① Code.gs 의 `FOLDER_ID` ② data.js 의 `appsScriptUrl` |

---

## 1. 구글 계정 · 저장 폴더 만들기
1. 기관 공용 구글 계정으로 https://drive.google.com 로그인 (예: kar0159@kar.re.kr 로 만든 구글 계정)
   - 이 계정이 파일의 **소유자**가 됩니다. 담당자 개인 계정보다 공용 계정을 권장합니다.
2. **새로 만들기 → 새 폴더** → 이름 : `자격인증 신청 증빙서류`
3. 폴더를 열고 주소창에서 폴더 ID 를 복사합니다.
   `https://drive.google.com/drive/folders/`**`1AbCdEfGhIjKlMnOpQrStUvWxYz`** ← 굵은 부분
4. **담당자 계정에 폴더 공유** : 폴더 이름 오른쪽 클릭 → **공유** → kar0159·kar0156 담당자의 구글 계정 추가(권한 : 편집자) → **일반 액세스 : '제한됨'** 그대로 둠
   - ⚠ '링크가 있는 모든 사용자'로 바꾸지 않습니다. 메일이 다른 사람에게 전달돼도 서류가 보이지 않게 하기 위해서입니다.
   - 담당자는 메일의 링크를 열 때 이 구글 계정으로 로그인해 있어야 합니다.

## 2. Apps Script 만들기
1. https://script.google.com → **새 프로젝트**
2. 왼쪽 위 '제목 없는 프로젝트' → 이름 : `KAR 자격인증 신청 수신`
3. `Code.gs` 의 기존 내용을 모두 지우고, 저장소의 **`docs/apps-script/Code.gs`** 내용을 그대로 붙여 넣기
4. 맨 위 `CONFIG` 에서 **★ FOLDER_ID** 를 1단계에서 복사한 값으로 바꾸기 → 💾 저장(Ctrl+S)

```js
var CONFIG = {
  FOLDER_ID: '1AbCdEfGhIjKlMnOpQrStUvWxYz',   // ← ★ 여기
  MAX_TOTAL_MB: 15,
  ALLOWED_EXT: ['pdf', 'hwp', 'docx', 'xlsx', 'jpg'],
  KEEP_DAYS: 30,
  MAX_PER_10MIN: 40,
};
```

## 3. 권한 승인 · 자동 정리 예약 (처음 한 번)
1. 위쪽 함수 선택 칸에서 **`checkSetup`** 선택 → **▶ 실행**
2. '승인 필요' → **권한 검토** → 1단계의 계정 선택
   - "Google에서 확인하지 않은 앱" 화면이 나오면 **고급 → KAR 자격인증 신청 수신(으)로 이동(안전하지 않음)** → **허용**
   - 직접 만든 스크립트라서 나오는 정상 안내입니다. 드라이브 접근 권한을 이 스크립트에 주는 단계입니다.
3. 아래 '실행 로그'에 `저장 폴더 확인 : 자격인증 신청 증빙서류 …` 가 보이면 폴더 ID 가 맞습니다.
4. 함수 선택 칸에서 **`setupDailyCleanup`** → **▶ 실행** → 로그에 `자동 정리 예약 완료` 확인
   - 왼쪽 ⏰ **트리거** 메뉴에 `cleanupOldFolders` (매일) 가 생깁니다.

## 4. 웹 앱으로 배포
1. 오른쪽 위 **배포 → 새 배포**
2. 유형 선택(⚙) → **웹 앱**
3. 설정
   - 설명 : `v1`
   - **다음 사용자 인증 정보로 실행 : 나(…)** ← 파일이 이 계정 드라이브에 저장됨
   - **액세스 권한이 있는 사용자 : 모든 사용자** ← 신청자가 로그인 없이 올리려면 반드시 이 값
4. **배포** → 나오는 **웹 앱 URL** 복사
   `https://script.google.com/macros/s/AKfycb..../exec`
5. 확인 : 이 URL 을 브라우저 주소창에 붙여 넣으면 `{"ok":true,"service":"KAR 자격인증 신청 증빙서류 수신",…}` 이 보여야 합니다.

> **코드를 고친 뒤에는** 배포 → **배포 관리** → ✏ 수정 → 버전 : **새 버전** → 배포. 이렇게 해야 URL 이 그대로 유지됩니다. ('새 배포'를 누르면 URL 이 바뀌어 홈페이지 설정도 바꿔야 합니다.)

## 5. 홈페이지에 URL 넣기 (data.js)
GitHub 저장소 `data.js` → 연필(Edit) → `KAR.certApply` 의 ★ 표시를 바꿉니다.

```js
KAR.certApply = {
  // ★1. Apps Script 웹 앱 URL
  appsScriptUrl: "https://script.google.com/macros/s/AKfycb..../exec",

  // ★2. 신청 유형별 접수 메일 = FormSubmit Action 이메일 주소
  routes: {
    "신규 등록": { to: "kar0159@kar.re.kr" },
    "승급": { to: "kar0159@kar.re.kr" },
    "심사수행범위 추가": { to: "kar0159@kar.re.kr" },
    "갱신": { to: "kar0156@kar.re.kr" },
    "전환": { to: "kar0156@kar.re.kr" },
  },
  ...
  maxTotalMB: 15,          // Code.gs 의 MAX_TOTAL_MB 와 같게
  accept: [".pdf", ".hwp", ".docx", ".xlsx", ".jpg"],   // Code.gs 의 ALLOWED_EXT 와 같게
```
- URL 이 예시값이면 화면에 "관리자 안내 : 설정되지 않음" 문구가 뜨고 제출되지 않습니다.
- **Commit changes** → 1~2분 뒤 반영

## 6. FormSubmit 활성화 · 시험
1. 실제 홈페이지 주소에서 `data.js` 의 `debug: true` 로 바꾸고 시험 신청 (작은 PDF 1~2개)
   - '신규 등록'(→kar0159) · '갱신'(→kar0156) 각 1회
2. 처음이면 각 메일함에서 FormSubmit 확인 메일의 **Activate Form** 클릭 → 다시 시험 신청
3. 확인
   - [ ] 드라이브 `자격인증 신청 증빙서류` 폴더에 `KAR-…_홍길동_신규 등록` 폴더와 파일이 생긴다
   - [ ] 메일 표에 **첨부파일_폴더 · 첨부파일_링크 · 첨부파일1_이름/링크…** 가 있다
   - [ ] 담당자 계정으로 로그인한 상태에서 링크가 열린다 / 로그아웃 상태에서는 '액세스 권한 필요'가 뜬다
   - [ ] 15MB 를 넘게 첨부하면 경고창이 뜨고 추가되지 않는다
   - [ ] '제출 중...' → "접수가 완료되었습니다." 팝업
4. 시험이 끝나면 `debug: false` 로 되돌리기

## 7. 문제 해결
| 증상 | 확인할 것 |
|---|---|
| "증빙서류 업로드 중 문제" | 웹 앱 '액세스 권한 : 모든 사용자' 인지 · data.js 의 URL 이 `/exec` 로 끝나는지 · 코드 수정 후 '새 버전' 배포했는지 |
| debug 에 "응답이 JSON 이 아님" | 배포 설정 오류(로그인 화면 HTML 이 돌아옴) → 4단계 다시 확인 |
| 드라이브에 파일이 안 생김 | Code.gs 의 FOLDER_ID · 3단계 권한 승인 · Apps Script 왼쪽 **실행** 메뉴의 오류 기록 |
| 메일에 링크가 없음 | 링크를 받지 못하면 메일을 보내지 않도록 되어 있음 → debug 표시의 'Apps Script 응답' 확인 |
| 담당자가 링크를 못 엶 | 1단계 4번 폴더 공유에 그 담당자 구글 계정이 있는지, 그 계정으로 로그인했는지 |
| "신청이 많아 제한" | 10분에 40건 초과 — 정상 사용이면 Code.gs 의 `MAX_PER_10MIN` 을 늘린 뒤 새 버전 배포 |

## 8. 개인정보 · 보안 메모
- 폼 아래 안내 : "※ 신청 시, 개인정보 이용에 동의한 것으로 간주하며, 첨부파일은 한국심사자격인증원 구글 드라이브에 30일간 보관 후 자동 삭제되고, 신청 내용은 FormSubmit 서버에 30일간 보관됩니다."
- 구글 계정에는 2단계 인증을 켭니다. 이 계정의 드라이브에 신청인 서류가 쌓입니다.
- 웹 앱 URL 은 홈페이지 소스에 공개되지만, 이 URL 로는 **파일 올리기만** 가능합니다(목록 조회·내려받기·삭제 기능 없음).
- 무료 구글 계정 드라이브 용량은 15GB(Gmail·포토와 공유)입니다. 30일 자동 정리로 쌓이지 않게 합니다.
- 개인정보처리방침의 '처리 위탁(구글 · FormSubmit)' 반영 여부를 개인정보 담당자와 확인하세요.
